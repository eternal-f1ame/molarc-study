# MolARC-9 human study

The study page for the MolARC-9 puzzle benchmark: https://sochastic.me/molarc-study/

Open the page, enter an alias and your background, do the two practice puzzles, then the 36 study puzzles. Each puzzle shows demonstration pairs (input grid, output grid) that follow one hidden rule and a test input. Fill in the output grid for the test input. You get two attempts per puzzle. Take as long as you need.

`index.html` is generated by `python -m molarc.puzzles.human export` in the MolARC-9 repository. Do not edit it by hand.
