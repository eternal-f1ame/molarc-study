# MolARC-9 human study

The study page for the MolARC-9 puzzle benchmark: https://sochastic.me/molarc-study/

Open the page, register, do the two practice puzzles, then the nine study puzzles. Each study puzzle hides a reagent. The demonstration pairs (input grid, output grid) show what the reagent does to a few molecules, and the corner cell of each input labels the reagent. Fill in the output grid for the test input. You get two attempts per puzzle. Take as long as you need.

Since 2026-10-18 the page shows tasks of release v3. The release v1 page (36 study puzzles) is in the history of this repository, and the release v2 pilot is at `pilot/`.

`index.html` is generated by `python -m molarc.puzzles.human export` in the MolARC-9 repository. Do not edit it by hand.
